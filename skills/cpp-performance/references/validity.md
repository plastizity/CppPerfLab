# Agent：性能主张与实验有效性

先阅读 [使用方责任边界](../../../USAGE.md#平台与使用方的约定) 和
[实验有效性指南](../../../guides/experiment-validity.md)。使用 schema 查询实际
字段，选择调用范围并预览完整预算；目标、状态动作和 oracle 都是受信命令。

区分使用方声明、平台执行事实与消费者验证范围。状态动作成功不证明状态等价，
已记录工作计数相等不证明全部工作相等。已有全过程时间和可信 oracle 在其
范围内仍有用；必要条件缺失时不得把指标升级为有效主张或根因。

按探索 → 固定候选和规则 → 新测量确认 → 工程验收组织现有 Study；A/A 是显式
可选校准，不自动扣噪。查看 workflow 来源、validity、原统计改善、
claim_acceptance 及资源回退；workflow PASS 只代表所记录来源和冻结检查，不
等于加速或批准采用。请求旧记录时保持 NOT_CONFIGURED，不补造确认。

使用者提供状态、工作语义和验证覆盖；平台不清系统缓存、不推断应用快照，
也不宣称 Run ID 的不同能证明统计独立或对未观察输入泛化。
