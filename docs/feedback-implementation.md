# 使用反馈与新需求：实施及验收清单

本清单保留完整目标；单项通过不代表整项改进已经完成。平台不读取、修改或
编译使用方业务仓库，不提交业务身份、数据或日志。接口与验证使用合成样例。

## 两条接入路径，共享底座

1. **生产程序性能观测**：程序/使用方转换器导出通用阶段记录及样本引用。
2. **独立代码性能实验框架**：小型 C++ 适配器加载字符串/文档/文件，准备对象、
   调用函数/类、验证结果；支持不同生命周期和状态重置条件。

二者共享 Metric Registry、六态 Evidence、Adapter、run、Store、Comparison、
统计验收、CLI、Skill 和报告；不建立第二套执行器、计时调度器或数据库。

## 依赖与继续顺序

F01/F02 → F03/F06 → F04 → F05/F07 → F08；F09/F10/F11/F12 按现有契约
和可用工具推进。生产日志通过使用方的格式/关键字配置接入，平台维护统一
协议与统计；不再以索取业务样本作为平台建设前置。生产程序完整构建代价高，先复用
已有产物和导出文件；仅显式构建平台内的小型合成验证目标。

每项需要：外部输入校验、原始证据、兼容性/失败测试、实际接口验证及明确限制。
只有设计、未实测、不支持和已验证状态必须分别报告。当前整体目标保持进行中。

F12 已补充规模/强扩展、paired、cases、assessment 的创建时父子关联，Study
级状态、活性、计数与当前执行链已通过真实规模和嵌套联合评估验证；
`history --kind study|all` 可直接发现进行中的父级记录。Run 全过程 ETA 已用
三次真实串行运行验证：前两次记录完整成本，第三次取得 5 次 Estimated 查询；
未启用持续进度写入，6 个正式目标样本保存在既有 Run/Store 中。完整成本不是
目标程序性能时间；历史范围不是置信区间。工具或平台实现执行期间改变时，
成本证据 Invalid，不得进入历史。Study 全过程 ETA 仍为 Missing，
不跨异构规模/输入猜测。合成验证记录：
`20261026T083524-e4a0160ad2e9`、`20261026T083526-e63de5dcf7d2`、
`20261026T083529-069ea439785f`；原始证据保留于本地 Store，不入库。
后续优先推进缺失功能；验证以改动直接相关的检查和必要真实接口为限，
已有检查通过后不无故扩展或重复测试。

按使用方最新优先级，先完成反馈闭环，不继续扩展独立函数/类框架。当前保留
的限制是 OS 级调度时间线、受串行实验约束的同步竞争双跑，以及 Study 或缺少
匹配历史时的全过程 ETA；这些限制不能被应用标注、Missing 或一般 PASS 掩盖。
